# Lexium

Senior Computer Science Students' Graduation Project at FCAI-CAPU

## Instructions on Getting Started

Set up required Runtimes and Dependencies, the links provided assume you are running Windows on an x86_64 system.

- [Java 25](https://www.azul.com/core-post-download/?endpoint=zulu&uuid=b9ca902c-6de8-4264-ab12-000314245dc5)
- [NodeJS 26](https://nodejs.org/dist/v26.12.1/node-v26.12.1-x64.msi), if you encounter any issues installing Node on Windows, disable Smart App Control in the Windows Security app.
- [Python 3.14](https://www.python.org/ftp/python/3.14.9/python-3.14.9-amd64.exe)
